# Accuracy Rules

## Core rules

1. Keep source-faithful notes separate from your own synthesis.
2. Do not infer missing facts from context alone.
3. Do not write speculative language as if it were verified fact.
4. Treat citations as a verification system, not decoration.
5. Prefer a short, precise note over a long, unsupported one.
6. If uncertainty remains, remove the sentence.

## Claim standards

A useful claim has three qualities:

- it is bounded
- it is traceable to a source
- it is distinct from a general concept summary

## Practical test

Before finalizing a note, ask:

- What exact source supports this?
- Is the wording source-faithful?
- Is this a citation or an interpretation?
- Would this still be true if I removed all context and assumptions?

If the answer is unclear, the note should not be kept in its current form.
