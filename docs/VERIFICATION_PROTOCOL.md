# Verification Protocol

This project follows a strict verification protocol.

## Principle

Nothing in the wiki should enter as a confident statement unless it is grounded in a read source or a verified bibliographic record.

## Required workflow

1. Read the primary source.
2. Confirm the exact citation information.
3. Extract the claim or detail in context.
4. Record whether the point is a direct citation, a summary, or your own interpretation.
5. Only then add it to the wiki.

## Acceptable evidence

- the paper itself
- a directly downloaded PDF of the source
- verified metadata from the publication record
- a full-text source file you have inspected

## Unacceptable evidence

- abstract-only summaries
- AI-generated recollection
- review articles used as substitutes for the primary source
- vague plausibility or likely interpretation without source support

## Rule when evidence is missing

Leave the section blank. Do not fill the gap with an educated guess.
